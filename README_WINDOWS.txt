HUONG DAN CHAY DASHBOARD TREN WINDOWS
=====================================

1. Giai nen toan bo thu muc vao mot noi bat ky.
2. May can Python 3.10+.
3. Lan dau, nhap dup vao file:
      start_dashboard.bat
4. Cua so Dashboard se tu tao moi truong chay va cai cac thu vien.
5. Trinh duyet se mo tai:
      http://127.0.0.1:5000
6. Dang nhap bang tai khoan duoc cap.

Tai khoan mau ban dau:
  admin
  Mat khau: CDRDHNN123

Luu y:
- Khong xoa file cdr_dashboard.db.
- Khong chia se file nay cho nguoi khong co quyen.
- Muon cap nhat du lieu Excel: dang nhap admin -> Quan tri -> Upload Excel.
- Dashboard nay chay tren may hien tai. De nhieu may cung truy cap, can trien khai tren may chu noi bo.
